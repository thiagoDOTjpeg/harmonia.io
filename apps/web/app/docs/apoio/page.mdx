# Apoie o Projeto

O **Harmonia.io** é um projeto 100% Open Source, desenvolvido e mantido por paixão à engenharia de software.

Manter a documentação, corrigir bugs e criar novas features consome muitas noites e fins de semana. Se este projeto te ajudou a aprender Clean Architecture, estudar Monorepos ou simplesmente salvou suas playlists, considere apoiar!
